# Advanced Aviator Risk Analyzer starter

## Included
- `bot.py`: Telegram bot commands `/add`, `/stats`, `/risk`, `/estimate`, `/recent`
- `dashboard.py`: mobile-friendly Streamlit dashboard
- `requirements.txt`: Python dependencies

## Run
Python 3.11+:
1. `pip install -r requirements.txt`
2. Create a bot using https://t.me/BotFather
3. Set `TELEGRAM_BOT_TOKEN` as an environment variable. Never put the token in a public file.
4. Run `python bot.py`
5. In a second terminal run `streamlit run dashboard.py`

## Shared database
For bot and dashboard to share data, run both in the same environment with the same persistent `aviator.db`. Separate cloud services will have separate local SQLite databases. Production deployment should use a shared database or one host with persistent storage.

## Limits
No exact-next-multiplier prediction is possible from prior multipliers alone when outcomes are generated by a secure random/provably fair system. `/estimate` creates a transparent smoothed historical baseline, not a reliable next-round signal. Automated result scraping, account login, and betting are not included.
